# Git Command Cheat Sheet

* **Check Git Version:** `git --version` - Check the installed Git version.
* **Configure Username:** `git config --global user.name "Your Name"` - Set your Git username[cite: 7].
* **Configure Email:** `git config --global user.email "your@email.com"` - Set your Git email address[cite: 7].
* **Display Configuration:** `git config --list` - Show Git configuration information[cite: 7].
* **Clone Repository:** `git clone <url>` - Download a GitHub repository[cite: 7].
* **Check Status:** `git status` - Display file status[cite: 7].
* **Add Files:** `git add .` - Add all modified files to staging[cite: 7].
* **Commit Changes:** `git commit -m "message"` - Save changes locally[cite: 7].
* **Upload to GitHub:** `git push` - Upload local commits to GitHub[cite: 7].
* **Download Updates:** `git pull` - Download changes from GitHub[cite: 7].
* **View Commit History:** `git log --oneline` - Display project history[cite: 7].
